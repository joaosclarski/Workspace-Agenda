## Stack Tecnológica

- **Framework:** Next.js (App Router)
- **Linguagem:** TypeScript (tipagem estrita obrigatória, evitar uso de `any`)
- **Estilização:** Tailwind CSS
- **Ícones:** Lucide React
- **Componentes:** Primitivos limpos (Shadcn/UI ou componentes modulares próprios)
- **Animações:** Framer Motion (para transições suaves, modais e efeitos de hover)
## Qualidade

Leia `CONSTRAINTS.md` antes de escrever código. Rode `npm run check:fast` após editar e `npm run check:task` antes de dar uma tarefa como concluída. Nunca enfraqueça `CONSTRAINTS.md` (nem adicione supressões) para fazer uma mudança passar.
